01 · Triage

Inbox zero, by default.

Review requests, mentions and discussions are scored for whether they need you. Replies are drafted with a confidence score and rationale, and dry-run mode keeps every draft a draft.

02 · Branch & fix

Reproduce first. Patch second.

It skips issues that already have an assignee or an open PR. The bug is reproduced with a failing test in an isolated sandbox before a single line of the fix is written.

03 · Watch

Every move, on one screen.

Mission control shows each worker, every task with its outcome and diff, the live event stream and your GitHub API budget. Pause, trigger a pass or switch modes from the same place.
